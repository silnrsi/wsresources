The Chrysanthi Unicode and Roman Unicode fonts include Tibetan characters
(borrowed from Arial Unicode MS) that are allocated to codepoints in the
Private Use Area and is "experiencing technical difficulties" according to
the Chrysanthi Unicode PDF file listing the Basic Multilingual Plane blocks
from the Unicode 3.0 standard by the font's author.

The Chrysanthi Unicode font contains scripts that Batang does not have, and
vice versa (This font supports Arabic, Armenian, Bengali, Bopomofo,
Chrysanthi Runes, Devanagari, Dlatci, Gujarati, Hebrew, Kanbun, Runic and
Tibetan while Batang supports Cyrillic, Greek, Hangul, Hanja, Hiragana,
Katakana and Latin).

The Roman Unicode font contains scripts that Times New Roman does not have,
and vice versa (This font supports Bengali, Bopomofo, Chrysanthi Runes,
Devanagari, Dlatci, Gothic, Hiragana, Katakana and Tibetan while Times New
Roman supports Arabic, Armenian, Cyrillic, Greek, Hebrew and Latin).
