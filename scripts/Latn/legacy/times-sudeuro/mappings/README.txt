Legacy font encodings: Ariel SudEuro, Ariena SudEuro, Bookman SudEuro,
Courier SudEuro, Garamond SudEuro, Times SudEuro, Verena SudEuro

Untested, and uncompiled, conversion tables for each set of fonts is included
here, which maps legacy encoded data to Unicode and vice versa. This set of
fonts contains symbols and a diacritical letter (l dot) at 80-9F, which ISO
8859-3 does not have.
