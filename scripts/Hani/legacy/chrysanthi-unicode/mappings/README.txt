The Chrysanthi Unicode font includes Han Ideographs (borrowed from MS Mincho)
that are allocated to codepoints in the Private Use Area by the font's author
(Contains numbers, directions, seasons, elements, horary characters, zodiac
animals, and characters necessary to write the names of the solar terms). The
font's author said that "the entire subset was not present due to space
considerations", according to the PDF file listing the Basic Multilingual
Plane blocks from the Unicode 3.0 standard.

The Chrysanthi Unicode font contains scripts that Batang does not have, and
vice versa (This font supports Arabic, Armenian, Bengali, Bopomofo,
Chrysanthi Runes, Devanagari, Dlatci, Gujarati, Hebrew, Kanbun, Runic and
Tibetan while Batang supports Cyrillic, Greek, Hangul, Hanja, Hiragana,
Katakana and Latin).
