Untested, and uncompiled mapping file for Fingertip Software, Inc. (Cyrillic) 

Character Set Converter (Fingertip Software, Inc., 2000) and its predecessor,
Cyrillic Central, contains precomposed Cyrillic letters with acute and grave
accents to mark stressing, that are allocated to codepoints in the Private
Use Area (used in the Academic Russian and WordPerfect Cyrillic A encodings).
