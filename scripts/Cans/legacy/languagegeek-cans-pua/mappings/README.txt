Unicode PUA encoding: Languagegeek Canadian Syllabics

Untested, and uncompiled, conversion tables for each set of fonts is included
here, which maps Canadian Syllabics encoded in the PUA using the Aboriginal
Sans (2005), Aboriginal Serif (2003), Kayases (2006), Kisiska (2005),
Masinahikan (2005), Masinahikan Dene (2005), OskiBlackfoot (2004), OskiDakelh
(2004), OskiDene (2005), OskiEast (2008), OskiWest (2008) or Pitabek (2005)
fonts.
