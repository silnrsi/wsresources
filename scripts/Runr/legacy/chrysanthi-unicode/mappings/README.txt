The Chrysanthi Unicode font includes Runic characters that are allocated to
codepoints in the Private Use Area by the font's author.

The Chrysanthi Unicode font contains scripts that Batang does not have, and
vice versa (This font supports Arabic, Armenian, Bengali, Bopomofo,
Chrysanthi Runes, Devanagari, Dlatci, Gujarati, Hebrew, Kanbun, Runic and
Tibetan while Batang supports Cyrillic, Greek, Hangul, Hanja, Hiragana,
Katakana and Latin).
