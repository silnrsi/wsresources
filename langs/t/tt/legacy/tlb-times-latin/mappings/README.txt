Untested and uncompiled mapping tables are included here, which converts Tatar
text written in the Kazan Latin alphabet with the TLB Times font to Unicode
and vice-versa.

TECkit mapping file for TLB Times (used when writing Tatar with Latin letters, but not with the Cyrillic script), which has the Turkish letters at the same positions as in ISO-8859-9 and Windows Turkish (Code Page 1257).
