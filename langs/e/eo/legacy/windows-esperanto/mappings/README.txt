Legacy font encodings: 3vgafix.fon and 3vgasys.fon

This encoding was created by Pejno Simono (Flandra Esperanto-Ligo) and used in
Capelilo (word processor). It is compatible with ISO 8859-3, provides national
characters on the same points as with ISO 8859-3, but is limited to Esperanto
glyphs only. To install versions of Fixedsys and System with Esperanto
characters in their bitmaps which override the font files on the Windows system
directory using a batch file, please visit http://www.esperanto.be/tiparoj.html
(page in Esperanto)
